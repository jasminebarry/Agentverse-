# Superseded — safe to delete

These are the first-draft files from an earlier session. They were replaced
by `loop/`, which is the working version.

Why they are not the ones to use:
  * `run_loop.py` / `designer_agent.py` / `critics.py` here import
    `pipeline_adapter`, which was never written into this folder, so none of
    them actually run (`ModuleNotFoundError`).
  * They used mock chemistry. `loop/` runs real RDKit, real AutoDock Vina
    and a real MRP1 receptor.

One idea in here IS better than the current version and is worth stealing:
`run_loop.py` ran the critics BEFORE docking, so a molecule the process
critic would reject never costs a docking run. `loop/` docks first. That
mattered more when a dock was assumed to take minutes; measured, it is ~12 s,
so the current order is defensible — but gating first would still be faster.

Delete this folder whenever you like:  rm -rf _superseded
