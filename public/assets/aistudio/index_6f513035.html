Closed-loop molecule design

Generative chemistry outputs molecules nobody can manufacture. We close the loop with a process-chemistry critic.
waiting…
The reference ligand is what tells us where on the protein to dock — we box the grid around it. A pose file (.pdb/.sdf from the crystal structure) is best. SMILES alone names the molecule but gives no position, so without a pose file we dock blind against the whole protein: much slower and less reliable.

live, cache and mock start round 1 from the real generative output in runs.db — the molecules that dock best and cannot be made. fresh lets the designer invent round 1 itself, which usually converges immediately.
